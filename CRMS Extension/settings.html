CurrentRMS Helper Settings

Version:

Settings

Use CurrentRMS Helper Sounds

Enabling this option will trigger alternative sounds and voice prompts when scanning items in detail view. It is recommended that you mute the normal CurrentRMS sounds if using this feature (to avoid double pings).

Allocate View by Default

By Default, when the Details View page loads, you start on the Functions tab, which is rarely where you want to be. This feature automatically puts you into Allocate, so that you're ready to start scanning.

Mark As Prepared on Page Load

Many users don't typically use the Allocate step of current-rms, and instead go directly from Reserved to Prepared. By default, the "Mark as Prepared" setting is off, meaning it needs to be turned on after every page load. This feature ensures that Mark As Prepared is On by default.

Inspection Alerts

By default, current-rms provides no audible warning if an item is scanned which is overdue an inspection. This often means returning to the screen to discover an item you scanned 10 minutes ago (that is now buried in a flightcase) needs to be tested. This feature introduces audible warnings when the item is scanned. "Full" means a voice will report "Inspection overdue for item XXXXXXX". "Short" means a voice will report "Inspection overdue".

Block Quarantined Allocations *

By default, current-rms will allow an item in quarantine to be allocated to an opportunity; even if that item is in quarantine because it is unsafe to use. This feature will attempt to block quarantined items from being scanned. Note: Due to how current-rms works, this block is not guaranteed to work in all circumstances. For example, items that have only been quarantined a few minutes before being allocated.

Global Check-in Dialog Override

In Global Check-in, by default a scanned item that is booked out on multiple opportunities will invoke a dialog box to ask which opportunities it should be returned from. In practice, the answer is almost always "all of them", but the need to click this button on the dialog box disrupts the scanning process. This feature automatically selects all opportunities listed for a scanned item and closes the dialog box automatically.

Error Message Timeout

This feature will automatically dismiss error messages that appear during scanning. This can be useful when using hand held devices where the message is immediately visible to the user. A setting of 0 seconds disables this feature.

Auto Book Out Nested Containers

When enabled, this feature will automatically book out any items that are contained within the scanned item. For example, scanning a flightcase to book out will cause the flightcase's contents to also be booked out.

Disable Detail View Delete

This feature disables the controversial button that allows items to be easily deleted from the Detail View list.

Show Collapsed Item Totals

In Order View, when an item has accessories but the item is in a collapsed state (accessories are hidden) the total now reflects the item charge plus any charges for accessories inside it. Mousing over this total reveals the item's individual charge. Clicking on it expands the acessories below.

Smart Scan by Default *

Normally, any item scanned will be allocated to the first available product line in the opportunity. This can cause issues where common accessory items (such as power cords) become associated with the wrong parent product. Smart Scan attempts to rectify this, by keeping track of the last item scanned and then attempting to pair the next item with an accessory.

Container Check *

Normally, Current-RMS will allow you to scan a serialised container onto an opportunity, even if the contents are not required at all. For example, if you have cases of 6 x LED tiles containerised, and a job requires 12 tiles, the system will allow you to scan 3 cases (or more) without warning. With Container Check enabled, a list is formed of containerised assets each time the API data is updated (automatically every 30 minutes). To be valid, a container must contain at least one unnallocated item that is not an 'Accessory Only' product. You can defeat Container Check if required by using Free Scan.

* Requires API key to have been entered.

Local Data

API Product & Stock Snapshot *
Updated:

Some features of the extension rely upon having an offline list of the product and stock inventory. This "snapshot" is automatically updated from time to time, but in some cases you may need to force it to be refreshed.

Quarantine Data *
Updated:

For the "block quarantined items from being scanned" feature a list is kept of the currently quarantined items. This is because to make an API call during every scan to check if an item is in quarantine is too slow. This list is automatically refreshed every so often, but in some cases you might need to force it to be refreshed.

* Requires API key to have been entered.

API Details

Company Subdomain
.current-rms.com

API Key

As stated by CurrentRMS: "API Keys give read and write access to your Current RMS System. You should keep your keys safe just as you do your username and password - only use them with software and services that you trust. Give each key a unique name so you can clearly identify who you have issued the key to."

THEREFORE: Do not enter your API key unless you have authority to do so. API key information is stored using chrome.storage.local. Though it isn't sent anywhere outside of your system (beyond making API calls), it is not encrypted, and is only as safe as your system.
